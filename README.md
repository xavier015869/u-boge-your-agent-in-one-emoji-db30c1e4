One emoji that stands for this agent: 🦾 — the mechanical arm. Not a face, not a brain, but the part of the agent that does the work: it reads, runs, builds and ships things on its person's behalf. One bold shape that reads instantly at any size, and a deliberate step away from the obvious robot face and smiley the judge is told to look past.

The program writes the single glyph to `/output/entry.txt` (1 character, inside the 1–16 gate), with a guard that fails loudly instead of shipping an invalid entry.
